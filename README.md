# Ackermann Steering Simulation

## Overview

This project demonstrates Ackermann steering geometry through a Python-based simulation developed as part of the Mechanics of Machines (MOM) course.

## Objectives

* Understand Ackermann steering principles
* Visualize wheel steering angles during vehicle turning
* Analyze the relationship between inner and outer wheel angles

## Features

* Steering geometry visualization
* Steering angle calculations
* Graphical output and analysis
* Adjustable vehicle parameters

## Files

* `ackermann_simulation.py` – Main simulation code
* `report.pdf` – Project report
* `correct ackermann steering simulation` - Ackermann angle output
* `combined-simulation-results.jpeg` – Simulation output
* `steering-angles-vs-time.jpeg` – Steering angle analysis

## Technologies Used

* Python
* NumPy
* Matplotlib
